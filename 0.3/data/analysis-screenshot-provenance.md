# Example analysis screenshot

This note documents the screenshot used in the README.

- **Reference image:** `olive-peacock-spot-branch-reference_d9800f54.jpg`, uploaded to the project storage only for this documented interface test.
- **How it was used:** The image was loaded into the normal CropGuide upload screen and the normal **Analyse image** button was used.
- **Actual crop result:** Olive (`Olea europaea`) at 0.975 Plant.id probability.
- **Actual visible-symptom output:** circular dark spot, yellow halo, upper leaf spot, leaf spot, dark brown spot, and yellowing.
- **Actual matching result:** `olive_peacock_spot` was the first returned candidate. Other candidates remained possible results, not confirmed diagnoses.

The image is a public visual reference found through image search. It is used only to show the application flow in the README. The screenshot must keep the app's own warning that an image result is not a confirmed diagnosis.
