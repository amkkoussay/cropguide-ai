# CropGuide AI

## Version 0.1

CropGuide AI is a web app for a first check of plant health from a photo.

## What is new

- Added the first working web app.
- Added photo upload for plant checks.
- Added crop and symptom analysis.
- Added a local plant data set.
- Added result, history, and map pages.
- Added a basic mobile-friendly layout.

## Run it

You need Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

## Important limit

This is an early check, not a final diagnosis. Do not use it as treatment advice. Ask an agriculture expert before making treatment decisions.
